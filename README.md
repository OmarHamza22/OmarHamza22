## 🔧 What I Actually Build

I don't just write code — I architect systems. Here's what that looks like in practice:

**🖥️ Backend Systems & APIs** — Production-ready RESTful APIs with layered MVC architecture, JWT/RBAC auth, rate limiting, and structured error handling. I think in contracts, not just endpoints.

**🗄️ Database Engineering** — Schema design from scratch: ER modeling, migrations, query optimization, Redis caching. Designed 15-entity schemas with 31+ relationships and indexing strategies for real performance gains.

**🤖 AI & RAG Pipelines** — LLM-powered applications that are actually reliable: semantic chunking, FAISS vector retrieval, grounding validation guardrails, and structured evaluation frameworks. Not prototypes — production pipelines.

**🏥 Healthcare Data Engineering** — Software engineering rigor applied to biomedical problems: hospital systems, patient feedback intelligence, ECG signal processing.

**⚡ Real-time & Performance** — Socket.IO messaging/notifications, Redis caching layers, pagination design, and recommendation engines built to scale.
